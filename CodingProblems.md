# 🚀 Coding Interview Preparation Roadmap

This repository is a **comprehensive guide for coding interview preparation**.  
It starts with **daily warm-up problems (Day 1–20)**, then covers **topic-wise DSA questions**, and finally highlights the **LeetCode Top 75 Must-Do Problems**.

---

## 📅 Daily Warmup (Day 1–20)

1. Reverse a string  
2. Check if a string is a palindrome  
3. Print FizzBuzz (1–50)  
4. Find maximum number in an array  
5. Find factorial of a number  
6. Count vowels in a string  
7. Find sum of digits of a number  
8. Remove duplicates from an array  
9. Generate Fibonacci sequence up to n terms  
10. Find second largest number in an array  
11. Find minimum number in an array  
12. Check if a number is prime  
13. Find GCD of two numbers  
14. Count words in a sentence  
15. Find index of an element in an array  
16. Find missing number in 1…n  
17. Find largest word in a sentence  
18. Check if number is Armstrong number  
19. Find intersection of two arrays  
20. Sort array (without built-in sort)
